# qTarkovTracker

**qTarkovTracker** is a minimalist map tracker for Escape from Tarkov. It doesn't try to be an all-in-one super app — just a lightweight, native application built with Qt/C++ for cross-platform compatibility. No built-in browser, no unnecessary complexity.

## Features

Shows on the map:
- Your current location and facing direction.
- Quest locations.
- Extraction points.
